PCL-QW

基于 Plain Craft Launcher 2（PCL2）2.13.1.1 源代码制作的第三方社区修改版 Minecraft Java 版启动器。原版 PCL 由 龙腾猫跃 开发，本项目不改变其主体设计，只在实例管理、世界编辑、本地服务器与联机这几处做了扩展。

下载 Windows 版 下载完整源码

当前版本 2.13.1.1（PCL-QW mod-1.8）　·　大小 5.57 MB　·　无需安装，放到任意文件夹双击即可

关于 macOS 与 Linux：本项目只提供 Windows 版。PCL2 是 VB.NET + WPF + .NET Framework 4.8 程序，WPF 只存在于 Windows 版 .NET 中，因此无法在 macOS / Linux 上编译或运行，也没有 Wine 之外的官方方案。如果你需要跨平台启动器，请使用上游 HMCL 或 Prism Launcher（均为独立项目，与本修改版无关）。

首次运行

  1. 把 PCL-QW.exe 放进一个单独的空文件夹（不要直接丢在 .minecraft 里），双击运行。
  2. 首次会显示一次“PCL-QW 使用说明”，读完关闭即可，之后不再弹。
  3. 如果启动器没自动找到游戏目录，在弹出的选择框里指到已有的 .minecraft，或让它新建一个。
  4. 「设置 → 下载 → 社区资源 → 来源」建议保持“尽量使用官方源”；如果你的网络到 MCIM 镜像不通，选“尽量使用镜像源”会让模组列表每次多等 20 秒。

相对原版 PCL2 改了什么

所有改动都是增量的：原有功能、界面主色（蓝色）、正版购买劝导与赞助劝导均未改动。

实例库

顶部新增「实例库」标签，集中查看与启动全部实例。单击实例进入管理，可查看并操作该实例的世界、资源包、光影、文件、服务器列表、日志。

世界设置

不进入游戏即可修改游戏模式、难度、允许作弊、世界显示名称与种子。直接读写 level.dat（gzip NBT），保存前自动备份 level.dat.bak，可一键还原。

一键版本升级

选择目标版本后自动安装新版本（含 Fabric / Forge / NeoForge 加载器识别），迁移世界、资源包、光影、配置与版本独立设置，并按新版本重新下载模组，未处理项写入迁移报告。

本地服务器

顶部新增「服务器」标签，实例页新增“创建服务器”。服务端建在该实例文件夹内，支持原版 / Fabric / Forge / NeoForge，启动器内直接启停、实时控制台、发送指令。

联机（陶瓦联机）

开源版原本隐藏了联机标签（官方实现依赖只有正式版能取到的在线配置）。本修改版把联机后端换成第三方开源工具陶瓦联机，联机标签与联机设置重新可用。

截图查看

实例页新增“截图”子页：缩略图墙 + 点击预览，支持放大查看、复制图片、复制并定位文件、重命名、删除（移入系统回收站）。

首页固定与最近游玩

首页新增「固定到首页」与「最近游玩」卡片，实例 / 世界 / 服务器都可一键启动。记录保存在启动器目录的 PCL\Recent.json，不写注册表。

下载任务页

「下载」标签页新增“下载任务”：总进度、正在下载哪个文件、已下载 / 总大小、实时速度、失败原因，可按任务取消。右下角浮标改为跳转到这里。

其他

设置导出 / 导入（JSON，不含账号与登录信息）；移除开源版不支持的“百宝箱”及其依赖的无效“内存优化”开关；下载线程默认值 63 → 85；列表改为后台加载不卡界面。

联机说明

联机功能由第三方开源项目 陶瓦联机（Terracotta） 提供，它基于 EasyTier 组网，由 Burning_TNT 与 Terracotta 贡献者开发，采用 AGPL-3.0 或更高版本许可（附带打包与进程间通信的例外条款）。

PCL-QW 只以未修改的可执行程序 + 本机接口的方式调用它：启动 陶瓦联机.exe --hmcl <端口文件>，再读写 http://127.0.0.1:<端口> 上的房间状态。不链接、不修改其任何代码，也不会把任何信息上传到本修改版的作者。

用法

  1. 进入「联机」标签，点“创建房间”，填一个联机昵称。
  2. 首次使用会自动下载陶瓦程序（约 8 MB），进度可以在「下载 → 下载任务」里看。
  3. 陶瓦会先扫描本地的 Minecraft 服务器：请在游戏内对局域网开放世界，或先启动一个本地服务器。
  4. 扫描到之后状态变为“已创建房间”，把房间码发给朋友，他们在“加入房间”里输入即可。
  5. 访客连上后地址形如 127.0.0.1:端口，在多人游戏里添加服务器，或用实例页的“联机”子页一键进游戏。
两个已知前提：①陶瓦同一时间只能运行一个实例，如果你自己开着陶瓦窗口，启动器会先结束那个窗口再接管；②房主必须有一个正在监听的本地服务器，否则会一直停在“正在扫描本地的 Minecraft 服务器”。

下载不通时：可自行从 陶瓦联机 Releases 下载 terracotta-<版本>-windows_x86_64-pkg.tar.gz，放入 %APPDATA%\PCL\Terracotta\；或直接把解压出来的 exe 改名为 陶瓦联机.exe 放在同一目录。

常见问题

模组 / 资源包列表加载很慢，甚至“版本加载失败”

多为两个原因之一：

  • 镜像源不通。「设置 → 下载 → 社区资源 → 来源」如果选了“尽量使用镜像源”，而你的网络到 mod.mcimirror.top 不通，每次请求要先等两次 10 秒超时才回落官方接口。改成“尽量使用官方源”即可。
  • CurseForge 没有 API Key。 官方发布由 CI 注入 Key，社区版没有。未配置时社区搜索会自动只走 Modrinth，不再表现为“加载失败”；需要 CurseForge 就设置环境变量 PCL_CURSEFORGE_API_KEY。

创建服务器时提示“没有找到可运行的 jar 文件”

mod-1.7 已修复。旧版本里下载步骤没有把文件列表交给下载器，导致什么都没下载。请确认下载任务页里能看到 <版本>-server.jar 正在下载。

服务器点了启动，窗口一闪就退出

最常见是 Java 版本不够。新版 Minecraft（如 26.x）的服务端需要 Java 25，而客户端实例可能是 Java 21。启动器会按服务端自身版本选择 Java；如果本机没有对应版本，会在控制台里看到 UnsupportedClassVersionError，去「设置 → 启动 → Java」安装或导入即可。服务器的全部输出也会写进启动器日志（PCL\Log1.txt）。

“最近游玩”是空的

需要成功启动一次游戏之后才会出现内容；「固定到首页」不依赖启动，随时可用。

世界设置改了没生效 / 显示不对

mod-1.4 起改用 level.dat 的真实字段（GameType / Difficulty / allowCommands）。如果你手上是很老的构建，请换新版本。另外修改种子只影响尚未生成的新区域，已探索区域不会变——这是 Minecraft 原生机制。

会上传我的信息吗？

不会。本修改版沿用上游开源版的行为：不启用匿名数据上报，没有自动更新，不拉取公告。设置导出为 JSON，且不包含账号与登录信息。

自建与发布（把这一页放到公网）

本目录本身就是一套完整的静态站点：index.html + PCL-QW.exe + PCL-QW-源码.zip + README-MOD.md。不依赖任何框架、构建步骤或第三方 CDN，双击 index.html 就能打开。要让它变成“永久公开网页”，把同一个文件夹原样挂到任意静态托管上即可。

方式一：本机起服务（最省事，适合先给朋友看）

目录里附带一个零依赖的 Node.js 单文件服务器 serve.js。在本目录打开命令行，执行：

node serve.js
# 默认 http://127.0.0.1:8080 ，可用 node serve.js 9000 换端口

它会自动列出目录文件并带上正确的下载文件名。想让局域网内的人访问，用 node serve.js 8080 0.0.0.0；换设备的话地址要用你这台电脑的局域网 IP。

方式二：静态托管（真正常态公开）

任选一个，做法都是「把这个文件夹整个传上去」：

  • GitHub Pages：把本目录内容推到仓库，Settings → Pages → Source 选 main 分支根目录，保存后一分钟内得到 https://<用户名>.github.io/<仓库名>/。
  • Cloudflare Pages / Netlify / Vercel：直接拖拽本目录上传即可，无构建命令、无输出目录要求。
  • 国内对象存储 + CDN（阿里云 OSS、腾讯云 COS、七牛等）：把四个文件作为静态资源上传并设为公共读，用自定义域名访问。这一步可以让国内用户免翻墙直接下载。
关于「永久」：上面的服务都是免费档，但都由第三方运营、需要你自己注册并保持账号有效，我不能替你在任何平台上创建账号或保证其长期在线。真正的“永久公开”= 你把这份静态目录放到一个你自己可控、且愿意持续续费的托管上；目录内容本身不包含任何会过期的东西。

发布时建议顺手做的两件事

  1. 页脚目前写着「见发布方 GitHub 仓库 frfhgrhff/cnm」但没有超链接，因为该仓库当前验证为不可访问。等仓库公开可用后，把页脚那行改成 <a href="https://github.com/frfhgrhff/cnm">frfhgrhff/cnm</a>。
  2. 把本页 <head> 里 description 的措辞按你的最终版本再核对一遍。上游要求第三方修改版的反馈由发布者承接，不要让用户去找 PCL 官方。
关于 hosts 劫持：如果你的机器上装了 Steam++ 之类的 GitHub 加速工具，访问 GitHub 前请确认它是否正在运行。本次验证时 C:\Windows\System32\drivers\etc\hosts 把 github.com 等全部域名指向了 127.0.0.1，由本机进程冒充 GitHub 返回页面——这种情况下无法判断仓库真实状态。上面「不可访问」的结论是在这个前提下得出的。

自行构建

依赖：Visual Studio 2022 BuildTools（.NET 桌面生成工具）+ .NET SDK 10.x。无需 Visual Studio IDE。

方式一：解压源码后直接运行仓库根目录的 build-mod.cmd（按需修改脚本内的路径）。

方式二：手动执行

set MSBuildSDKsPath=C:\Program Files\dotnet\sdk\10.0.401\Sdks
set DOTNET_ROOT=C:\Program Files\dotnet
"C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\MSBuild\Current\Bin\amd64\MSBuild.exe" ^
  "Plain Craft Launcher 2\Plain Craft Launcher 2.vbproj" -restore -p:Configuration=Release

产物：Plain Craft Launcher 2\bin\PCL-QW.exe

源码包不含 .git；仓库共 15 个提交，标签 mod-1.0 … mod-1.8，改动清单见源码包内的 README-MOD.md。
